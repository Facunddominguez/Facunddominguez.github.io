📲 Publicación e instalación

Versión {{VERSION}} · Abierta como archivo funciona igual que siempre; publicada en un sitio HTTPS se puede instalar y usar sin conexión.

Cómo se publica

  1. El código está en un repositorio de GitHub con GitHub Pages activado.
  2. Cada cambio que se sube corre las pruebas automáticas y, solo si pasan, publica la versión nueva.
  3. Una vez por mes, una tarea revisa los datos de nutrición de USDA y vuelve a publicar si cambiaron.

Para instalarla

  1. Abrí la dirección publicada en el celular.
  2. Elegí Instalar aplicación (o Agregar a pantalla de inicio).

Tus datos

Cada dirección guarda sus propios datos: lo que tenés en el archivo local no aparece solo en la versión publicada. Descargá un respaldo acá y restauralo en la versión publicada. Si publicás una copia de prueba, ponela en otro sitio: dos copias en el mismo sitio comparten los mismos datos. Las actualizaciones se avisan con un mensaje para recargar; tus datos no se borran.

Instalación disponible solo en la versión publicada con HTTPS.
